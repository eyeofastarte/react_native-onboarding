# Use of AI Tools

## Research & Learn

### AI tools used in my role
AI tools in my role include OpenCode and conversational AI tools like Kimi-K2.7-Code. These tools help with code completions and patterns directly in editors such as VS Code or Zed. Chat-based AI tools are useful for explaining concepts, debugging issues, and brainstorming possible solutions.

### Benefits and risks of using AI at work
AI tools help speed up development, especially for repetitive tasks or boilerplate code. They can also explain unfamiliar concepts and suggest possible debugging steps. However, AI can sometimes generate incorrect or outdated solutions. Using it without verification may introduce bugs or security problems. There is also a risk of exposing confidential information if sensitive data is shared with public AI tools.

### Information that should never go into AI tools
Sensitive information should never be entered into public AI tools. This includes API keys, passwords, authentication tokens, user data, personal information and more.

### Fact‑checking AI‑generated content
AI-generated content should always be verified before being used. I will run and test any code it produces, compare suggestions with official documentation, and check edge cases to make sure the solution works correctly.

## Reflection

### When to use AI versus my own skills
AI is useful for syntax help, boilerplate code, debugging hints, and learning unfamiliar tools or frameworks. For decisions that require deeper understanding, I will rely on my own reasoning and judgment.

### Avoiding over‑reliance
To avoid over‑reliance, I will try solving problems myself first. Then I may use AI to compare approaches or get additional ideas. If AI generates a full solution, I will review it carefully to ensure I understand how it works.

### Ensuring data privacy
To protect data privacy, I will avoid sharing confidential or proprietary information with public AI tools. If I need help with internal code, I will generalize the example so it does not reveal sensitive details.

## Task
- One task I improved with AI was finding and understanding hard‑to‑locate API documentation. AI helped point me toward the relevant sections of the docs and clarified how certain endpoints and parameters worked.
- One best practice I will follow at Focus Bear is treating AI as a helper rather than an authority. I will always review, test, and take responsibility for any code I use.
