# Learning Goals

My goal is to grow as a developer while engaging more with the Focus Bear community and helping other people study better. I want to share useful ideas, listen to user feedback, and contribute features that make study easier for everyone.

## 1) Core Coding Algorithms
- Arrays & strings: two pointers, sliding window, prefix sums
- Hash maps/sets, sorting, binary search
- Linked lists, stacks, queues, trees, heaps
- Graphs: topological sort, union-find
- Dynamic programming, greedy, recursion, backtracking

## 2) Core CS Concepts
- Big-O and data structure tradeoffs
- Memory basics: stack vs heap
- Concurrency basics: async, race conditions, locks
- Networking & databases: HTTP/APIs, indexing, transactions

## 3) AI End-to-End Loop
- Data prep: collect, clean, split
- Tokenization (BPE/SentencePiece) and embeddings
- Transformer block: RMSNorm, RoPE attention, MLP (SwiGLU)
- Training loop: forward pass, loss, backprop, AdamW, LR schedule
- Inference: KV cache, decoding (greedy/top-k/top-p/temperature)
- Quantization (4-bit/8-bit), evaluation, and iteration

## 4) React Native + Focus Bear Goals
- Improve React Native skills: navigation, hooks, state, performance
- Ship one small Focus Bear feature each cycle
- Fix one real bug or UX issue from testing/feedback
- Engage community, collect feedback, and share short updates
